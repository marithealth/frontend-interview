# Frontend Developer Technical Interview Exercise

## Overview

You'll be working on a **Doctor Job Finder** application - a tool that helps doctors find jobs and estimate salaries. This exercise is designed to test your debugging skills, problem-solving approach, and ability to work with modern development tools.

**Duration:** ~60 minutes  
**Focus:** Process over completion - we want to see how you think and work

## The Application

A Next.js app with React, Tailwind CSS, and Apollo GraphQL that allows doctors to:

- Browse job listings
- View salary estimates
- Share salary information with peers
- Filter jobs by specialty and location

## Your Tasks

### Phase 1: Initial Assessment (10 minutes)

1. **Explore the codebase** - understand the structure and identify any obvious issues
2. **Run the application** - get it working locally
3. **Document your findings** - what works, what doesn't, and your initial observations

### Phase 2: Debugging Challenge (25 minutes)

The application has several intentional bugs. Your job is to:

1. **Identify the issues** - find what's broken and why
2. **Fix the problems** - implement working solutions
3. **Explain your process** - walk through your debugging approach

### Phase 3: AI Tool Integration (15 minutes)

1. **Use AI tools** (Cursor, GitHub Copilot, etc.) to help solve remaining issues
2. **Show your workflow** - demonstrate how you leverage AI assistance
3. **Validate AI suggestions** - ensure the AI-generated code is correct

### Phase 4: Enhancement (10 minutes)

1. **Add a small feature** - implement one improvement you think would be valuable
2. **Explain your choices** - why this feature and how you implemented it

## Evaluation Criteria

- **Problem-solving approach** - how you break down issues
- **Debugging methodology** - systematic vs. random approach
- **Code quality** - clean, maintainable solutions
- **AI tool usage** - effective leverage of modern tools
- **Communication** - ability to explain your thinking
- **Time management** - how you prioritize tasks

## Getting Started

1. Clone this repository
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
   - This will start both the Apollo GraphQL server (port 4000) and Next.js app (port 3000)
4. Open [http://localhost:3000](http://localhost:3000)
5. GraphQL Playground available at [http://localhost:4000/graphql](http://localhost:4000/graphql)

## Notes

- Feel free to ask questions about requirements or business logic
- Use any tools or resources you normally would
- Focus on demonstrating your thought process
- Don't worry about completing everything - we're more interested in your approach

Good luck! 🚀
