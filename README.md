# Frontend Developer Technical Interview Exercise

## The Application

A Next.js app with React, Tailwind CSS, and Apollo GraphQL that allows doctors to:

- Browse job listings
- Filter jobs by specialty and location

## Getting Started

1. Clone this repository
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
   - This will start both the Apollo GraphQL server (port 4000) and Next.js app (port 3000)
4. Open [http://localhost:3000](http://localhost:3000)
5. GraphQL Playground available at [http://localhost:4000/graphql](http://localhost:4000/graphql)
